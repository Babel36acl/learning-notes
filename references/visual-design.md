# 面向阅读的 Obsidian 排版

用自然标题、连续段落、公式和具体例子的邻接建立层次。短观察可以没有小标题；长推导保留连续上下文。强调服务于关键区别，不把每句话都加粗。表格用于短项比较，长解释放回正文。

Obsidian 正文优先使用标准 Markdown、数学公式、原生 Callout 和 Mermaid。引用现有页时核实真实文件/标题/块，嵌入复用已有解释；有意未建页的概念线索按 Obsidian 约定保留。不要输出思源超级块、`#tag#`、AV 配置或 HTML 页面壳来替代正文。

## 默认发挥 Obsidian 特色（干巴是返工信号）

正式整理、MOC 与连续讲解默认就要有 Obsidian 味：连续三段以上纯段落、无链接无结构，先判定为没写完，而不是“简洁”。只有随手记与对象页可以零装饰（T36）。

- 双链成网：每页至少连向相关旧页（问题、方法、案例各找一个），MOC 用列表，每行 `[[库内路径|易读名]] — 一句话回答什么问题`；待确认的顺序用 `- [ ]` 任务行承载，不藏在段落里。
- 嵌入复用：已有解释用 `![[页#标题]]` 嵌入，不复制；同一概念只写一次。
- Callout 分层：`> [!warning]` 放不能怎么做、`> [!tip]` 放正确序列、`> [!question]` 放待核验；长推导的次要分支用 `-/+` 折叠；一般提示用行内 `💡 一句话`，不占用 Callout。类型与折叠以 kepano `obsidian-markdown` 的 CALLOUTS 为准，不自造类型。
- 对比用表：版本、对象、条件等短项比较用表，长解释回正文；公式讲清符号与前提。
- 图文紧邻：步骤一事一步（有序列表），图贴在该步下面并配一行斜体图注，不堆文末；`==高亮==` 只标关键区别，`%%注释%%` 藏草稿提示，脚注放出处。
- 可检索：Properties、标签（复用少量稳定词）、别名按需填，让页能被搜索/Bases 捞到；内外链分工是库内 `[[wikilink]]`、外部 `[text](url)`；Mermaid 只画因果/流程并说明连线含义。
- 各插件“该用时用哪一句”见 [插件与官方说明书分层索引](plugin-manuals.md)，默认只读该表，用谁读谁，不默认全读 16 份 README。

```markdown
> [!warning] 作用对象
> 终点钳位作用于参考轨迹；机械轴到位仍需实际反馈判断。
```

图用于因果、流程或同维比较，图中关系应明确。Canvas 适合知识结构，不能仅有节点名而缺少正文；交互 HTML 只有参数变化或逐步观察确有帮助时作为补充，核心解释仍保留在 Markdown。

图上的关系继承文字的证据边界；两节点有连线不证明因果，图谱稠密不证明理解充分。

沿用用户已有主题，确保中文、公式、代码、窄屏长表格可读。可用原生结构解决时优先原生结构；主题能力先核实本库是否真实可用，不为每篇安装依赖或全局改样式。

## Blue Topaz：在本库可用的部分（以主题说明书与示例为准）

阅读范围：`Blue-topaz-examples/00-Tips/🥑Blue Topaz Themes Tips.md`、`77-Example/ob提示框(callout)样式展示.md`、`77-Example/各级标题示例.md`、`README.md`（内置插件表、cssclass 表）。示例库排除在正式索引外，只作读法参考，不作工程事实。本库真实可用：主题 Blue Topaz（含 `artcore` 等 snippets）＋已装 style-settings、tasks、table-editor；无 dataview、admonition、buttons、kanban 插件。

- 标题：沿用单一 H1 规则。示例里连续两个 `# 一级标题` 就是反例；一级作文档标题、二级作章节（`各级标题示例.md:10-16`）。
- 强调：全文只选两三种并保持一致（Tips:54）。`==高亮==` 只标关键区别；多彩 `*== ==*` / `**== ==**` / `***== ==***` 需 style-settings 2.1.4 或单页 `cssclass: colorful-highlight`，默认不开。
- Callout：原生 13 类＋别名＋`-/+` 折叠＋自定义标题（`ob提示框:15-67`）。主题自定义只用纯 CSS 且免插件的：`[!cloze]` 模糊、`[!hibox]` 悬停隐藏、`[!blank]` 全透明、`[!indent]` 全文缩进、`[!left|center|right]` / `[!30%]` 布局与宽度；`kanban/bookinfo/timeline` 与旧 ` ```ad-xxx ` 代码块语法不用，伪看板改用原生列表或已装 tasks 承载。
- 每页 `cssclass`：沿用模板的 `artcore`；按需单页声明 `code-wrap`（代码换行）、`img-grid`（图片自适应）、`inline-list`（行内列表）、`fullwidth`（宽表）、`noyaml`（预览隐藏 frontmatter）、`cloze`（涂黑挖空）；不全局改样式（`Tips:459-501`，`README:114-145`）。
- 图片：`![[a.png|300]]` 缩放、`|R|L` 对齐、`|inl` 行内、`![[a.png#center|Figure 1|100]]` 加标题；`![]()` 用 `![|300](...)`、`![|R|150](...)`（Tips:224-321）。
- 任务：MOC 待办用 `- [ ]`；`[>] [<] [!] [?]` 等扩展勾选仅用于状态区分，不把项目待办推广到学习正文。
- Mermaid：主题已做宽度适配，直接写原生块（Tips:413-457）。
- 不引入：dataview/dvjs 查询、admonition 旧语法、buttons、主页脚本与移植教程；需要视图时先核实对应插件已装。

排版改动要在实际阅读视图看 Properties、公式、Callout、链接和附件；使用 Bases/Canvas 时检查对应视图。没有检查界面时只报告文件和索引层的结果。
